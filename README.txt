                             AllBinary Platform Perl

What is it?

This repository contains code generated by the AllBinary Platform for ArkTS and 
React Native support in Perl.  This repo is used to allow developers 
to skip the Perl code generation step.

What are some examples game with this Perl code?

https://allbinary.itch.io (The downloads with "-ts" in the filename are Perl only builds. Currently that only includes nothing. Also the Perl builds are not available on Google Play or other stores.)
